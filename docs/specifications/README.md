# Normative source documents

[SRS](SRS.pdf) and [Technical Development Requirements](Technical-Development-Requirements.pdf) retain the supplied normative page content. This neutral revision removes document metadata, including author fields and the original metadata stream. All 35 pages were checked for unchanged extracted text and pixel-identical rendering. [manifest.json](manifest.json) records both the original and revised SHA-256 values. The SRS retains its 2026 CC BY 4.0 notice and visible attribution. These are specifications, not implementation test evidence.

The source, implementation decisions and acceptance records must be read against these documents. No requirement has been waived. [Traceability](../requirements/traceability.md) distinguishes implementation from live acceptance and public delivery.
