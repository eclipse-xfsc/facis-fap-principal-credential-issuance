# Requirement implementation and acceptance — 0.5.0-rc.12

The supplied specifications are authoritative. Development **DONE** means the source implementation is delivered, not that formal acceptance has passed. **BLOCKED_OWNER** identifies a remaining end-to-end implementation dependency in owner-controlled infrastructure or native components. Overall PARTIAL records unexecuted build/live/review evidence; GAP / EXCLUDED records public or governance actions excluded from this source-only task. No excluded action is waived.

The 101 SRS IDs are unchanged. TDR-01 through TDR-07 are local audit groupings of unnumbered technical provisions; TDR-08 is the supplemental AI-assistance disclosure retained from the earlier audit, not an invented source requirement. The [83 individual technical clauses](technical-clauses.md) and their [machine-readable ledger](technical-clauses.json) prevent grouped rows from hiding a missing obligation. Original PDFs and hashes are under [specifications](../specifications/README.md). FR-81/82/83 correctly map to history / participant signing / participant-data internal signing.

SRS development counts: BLOCKED_OWNER 1; DONE 84; EXCLUDED 16. All formal acceptance remains evidence-gated.
