# 0.5.0-rc.1 release notes

Integration candidate, 5 October 2026. Not final sign-off.

## Changed

- Real native NATS/CloudEvent offers, callbacks, metadata read-back, TSA keys/signing and status allocation/revocation, derived from official source and the supplied ESB 12.3.6.
- Draft 13/final 1.0 request/response serializers, wallet proof/nonce checks, fixed public discovery/native endpoints and guarded tenant authority.
- Real HTTP/2 mTLS participant transport and Go/Goa reference service with two-call binding, deadlines, minimal claims, replay rejection and Crypto Provider Core signing.
- Volatile access-token/offer state, IdP roles/groups, Entra broker setup, passkey policy, safe native errors, counters and OTLP operation spans.
- Process-only connection/token caches prevent a disk-backed Node-RED context setting from persisting runtime secrets; obsolete context holders are cleared on upgrade.
- Published-issuer retirement withdraws configurations while preserving old credential verification; explicit policy decision remains required for complete deletion.
- G0 retains all live repairs: explicit Keycloak service/URL discovery, valid storage YAML, cache-free data migration, escaped container variables, persistent PostgreSQL password, SMTP sender configuration and Gateway header limits.
- Helm ownership, guarded uninstall, bounded resources, inactive mail path at zero replicas, no extra OCM stack, and no automatic OCM resource changes.
- Fresh Envoy bootstrap v1.9.2 and PCI-only proxy v1.39.2 follow the current security guidance; the supported Kubernetes range is 1.33–1.36. Existing shared controllers remain owner-managed.
- CI jobs, mandatory remote workflow calls, MkDocs, live PostgreSQL and XFSC Executor packs, full requirement mapping and a receipt gate that fails when evidence is missing.
- Source-pinned upstream patches remove observed sensitive payload logging; application to exact source bytes was checked, while builds and live privacy scans remain pending.

## Validation

See `validation.json` for actual counts and artifact hashes. Local Node tests, generated Function compilation, deterministic build, syntax and G0 YAML rendering were executed. Go/Goa compilation, Helm, live PostgreSQL/native/wallet/browser/cloud tests and official release/security/IP workflows were not executed here.

## Upgrade

Run the documented preflight and G0 command for the **new** OCM service layout. Import the new flow and replace UI assets; old imported 0.4.1 files do not gain these integrations automatically. Back up the DB and `/data` first. New runtime config may require one controlled rollout; artifact import does not require another restart.

## Keycloak networking correction (2026-10-05)

G0 now discovers the selected Keycloak Service's pods and target port and applies a separately owned NetworkPolicy in the OCM namespace. It permits PCI ORCE ingress and egress to PCI Mailpit/SMTP, retaining ESB policies and existing unrestricted directions. It rejects ownership collisions and ambiguous target ports. The policy remains outside PCI Helm ownership; runtime RBAC is unchanged. External broker HTTPS egress is still operator-managed.

Extract this updated source and rerun G0 with the deployment's existing arguments. This correction needs no flow/UI reimport. Kubernetes admission, login and email delivery must still be verified on the cluster; offline tests mock Kubernetes responses.
