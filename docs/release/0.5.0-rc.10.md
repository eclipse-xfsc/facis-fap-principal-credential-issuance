# 0.5.0-rc.10

> Application change record. Checks and deployment observations below describe this revision at the time of release. For current container distribution and CI results, see [package 1.0.0](1.0.0.md) and [executed checks](completion.md).

## Wallet discovery and credential-request sandbox corrections

The operator successfully installed rc.9 and confirmed Alpha metadata publication with desired 6 / observed 6. Public issuer discovery subsequently failed with `PCI-INTERNAL-500-001`. Its M11 stack maps to `pciWalletMetadata` in `backend/sr2/profiles.js`, which still called the host global `structuredClone`. The same source scan found a second call in `pciCredentialRequest`. The rc.9 VM tests covered native catalogue completion but missed the final wallet serializer.

Both profile helpers now copy JSON documents with `JSON.parse(JSON.stringify(...))`, supported inside Function nodes. They preserve the input, OID4VCI 1.0 and draft 13 field conversion, proof constraints and internal topic/schema removal. No Function-node body in the rebuilt distribution calls the unsupported host clone global. The public handler also translates trusted SR2 errors to their intended HTTP status/code, using the same approach as the authenticated handler; unclassified exceptions still receive a sanitized generic 500.

The expanded generated-flow sandbox tests execute the full public issuer and credential handlers with synthetic PostgreSQL and native HTTP boundaries. They check successful emission for both profiles, request conversion, native tenant headers, rate-limit execution, empty local catalogues, conflicting claims and tenant isolation. These tests run without injecting `structuredClone` or host JSON constructors. They are local regression evidence, not real wallet issuance or cluster acceptance.

The complete source retains previous publication, Bash authentication and jq verifier fixes. See [validation.json](validation.json), [the requirement audit](requirement-audit.md) and [the Bash upgrade](../operations/upgrade-0.5.0-rc.10.md). Live rc.10 discovery and issuance remain pending. Full SRS/technical acceptance is not claimed.
