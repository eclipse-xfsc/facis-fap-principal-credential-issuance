# 0.5.0-rc.2

7 October 2026. Source release candidate for the supplied OCM ESB 12.3.6. This package incorporates the patched source uploaded after the deployment session. It has not been deployed by the authoring environment and is not a completed sign-off receipt.

## Other deployment repairs retained

Explicit Keycloak service/URL selection; valid storage and mail YAML; dependency-cache-free `/data` transfer; escaped PostgreSQL/schema variables; persisted database passwords; bounded Keycloak networking; disjoint header set/remove lists; Helm 4 client-side adoption; correct `issuance-service`; IONOS `externalTrafficPolicy: Cluster`; one ORCE replica with `Recreate` for its RWO volume. A flow build ID refreshes cached native adapters on import, avoiding an extra ORCE restart for JavaScript changes.

Named participant trust Secrets have exact-name read grants and tenant ConfigMap ownership. Confirmed tenant deletion removes routes, owned configuration and associated Secret/RBAC children. Configuration archive preserves verification dependencies while the tenant remains active; full tenant deletion follows FR-27/66 and removes public resolution. It does not delete shared OCM workloads or silently purge external participant data.

The supplied telemetry deployment has one three-container Pod, no new public IP or persistent volume, bounded memory and six-hour metric retention. It is a test/review baseline, not an HA or durable monitoring service. See [telemetry](../operations/observability.md).
