# 0.5.0-rc.8

> Application change record. Checks and deployment observations below describe this revision at the time of release. For current container distribution and CI results, see [package 1.0.0](1.0.0.md) and [executed checks](completion.md).

## Corrected behaviour

Well-Known 1.5.2 returns published claim paths and mandatory flags but omits their optional display labels. PCI previously rejected that readback as `PCI-METADATA-READBACK`, even when OCM had stored the complete operational catalogue. Publication verification and public wallet discovery now complete only absent per-claim labels from the immutable local published configuration. Explicitly conflicting labels still fail. Issuer, endpoints, active configuration IDs, format, types, context, claims, mandatory flags, binding and proof algorithms remain checked. Native publication still checks schema and routing topic. Replies retain tenant/request correlation checks.

The regression fixture captures the synthetic Alpha issuer metadata returned on 2026-10-11. Public metadata is copied before completion, so native responses are never mutated. This correction does not change any OCM image or NATS subscriptions.

## Bash upgrade

[Upgrade instructions](../operations/upgrade-0.5.0-rc.8.md) use `scripts/upgrade-artifacts.sh` and the converted Bash/jq artifact installer. Neither invokes Python. Existing Node flow merge and runtime ownership components remain in use. Read requests have bounded retries; flow submission is attempted once. An ambiguous submission stops for operator review. Other inherited deployment/lifecycle tools have not all been converted to Bash.

The participant implementation is unchanged. The existing digest-pinned rc.7 participant image can stay deployed. No participant rebuild is needed for this correction.

## Validation and remaining acceptance

See [validation.json](validation.json) and the [requirement audit](requirement-audit.md). Local regressions and deterministic build checks are executed; deployment of this rebuilt release, Alpha catalogue convergence, wallet discovery and the remaining end-to-end tests require operator execution. Full SRS/technical acceptance is not inferred from local tests. The inherited shared-stack readiness/recovery, TLS, privacy, identity, native wallet, second-cloud and governance evidence gates remain explicit.
