# 0.5.0-rc.9

> Application change record. Checks and deployment observations below describe this revision at the time of release. For current container distribution and CI results, see [package 1.0.0](1.0.0.md) and [executed checks](completion.md).

## Source corrections from the rc.8 dev deployment

1. **Function-node metadata completion:** `structuredClone` is a host global unavailable in the deployed Function-node VM. Native catalogue completion now copies JSON documents with VM-supported JSON operations. The metadata contract is unchanged: only absent optional claim display labels are restored; substantive metadata and explicitly conflicting labels still fail. Captured native readback and generated M9/M11 helpers run in VM tests without injecting host clone globals. The generated service test verifies successful publication advances observed to desired; incorrect claims retain observed and error state.
2. **Editor authentication:** jq raw output appended a newline after the last form field, which changed the submitted password. Form generation now uses `jq -jnr`. Regression requests are decoded and checked rather than receiving a token for any body. CRLF file endings are covered.
3. **Installer verification:** the variable `$label` was rejected as a keyword by the operator's jq parser after the flow POST succeeded. The verifier now uses `$tab_name`. The installer tests emulate that exact older-parser rejection while using installed jq for other JSON operations. An actual jq 1.6 runtime is not installed in this local validation environment; the operator's UI-recovery command already exercised portable verifier syntax in the cluster deployment session.

All corrections are in canonical source and the normal regenerated distribution. No manual patches to released rc.7/rc.8 source are needed for this upgrade. The previous archives remain immutable.

## Deployment

Use the [Bash artifact upgrade](../operations/upgrade-0.5.0-rc.9.md) against the already prepared PCI runtime. The helper reads the existing private lifecycle JSON and password file, records source changes outside the repository, installs generated flows and UI, and verifies release health/readiness. Read operations have bounded retries. Flow submission has no automatic retry; ambiguous results stop for review. This release does not rebuild or replace the existing participant image or alter shared OCM services, tenant configuration or issuer resources.
