# FAP PCI container package 1.0.0

The container distribution is [`ecofacis/fap-pci:1.0.0`](https://hub.docker.com/r/ecofacis/fap-pci/tags?name=1.0.0) on Docker Hub. Packaging starts from the running `ecofacis/xfsc-orce:2.0.15` container, captures its filesystem and explicitly embeds `/data`, including PCI flows, configuration, UI assets and installed dependencies, before the resulting image is built and pushed.

The application source retains version `0.5.0-rc.12`. Container package 1.0.0 and the application version identify different artifacts; application files and version declarations are not renamed by this documentation update. The release includes the native signer JWK-array correction, existing discovery and public-key handling, tenant administration, issuance journeys and the participant integration interfaces.

Use the [container guide](../operations/container-image.md) for pull, digest inspection, persistent-volume behavior and runtime settings. The [source baseline](../source-baseline.md) identifies the reviewed Git commit. Capture the image's registry digest during release or deployment rather than deriving it from the repository commit or mutable tag.

[Executed checks](completion.md) and [workflow evidence](ci-evidence.json) describe source CI and documentation publication. Deployment test receipts identify their own environment, runtime version and image digest.
