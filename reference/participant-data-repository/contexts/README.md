Offline JSON-LD contexts
========================
The VC v1 context is transcribed from the complete cached context in W3C
Verifiable Credentials Data Model v1.1 (3 March 2022), appendix B.1:
https://www.w3.org/TR/2022/REC-vc-data-model-20220303/#base-context
The JWS2020 context is from https://w3c.github.io/vc-jws-2020/contexts/v1/ .
These W3C context documents retain their W3C document/software licensing:
https://www.w3.org/copyright/software-license-2023/
The loader resolves exactly these two URLs without network access. StatusList2021
entry terms are inline in the generated context, as defined by the 2023 report:
https://www.w3.org/community/reports/credentials/CG-FINAL-vc-status-list-2021-20230102/
json-gold v0.8.0 (Apache-2.0) supplies JSON-LD 1.1 / URDNA2015 processing.
